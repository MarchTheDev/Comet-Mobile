The native app, drawn in a browser: the desktop app's palettes, Manrope, flat bordered panels and compact type, laid out for a phone. A quick way to look at the design without a device — the real screens are SwiftUI.

9:41

What this is. A static reproduction of the app's interface for looking at, not the app itself. Notes, files, boards, feeds, calendar, vault, tools and the readers are all native SwiftUI in CometApp/; this page repeats the layout and the palette system in HTML so the design can be reviewed in a browser.

Try the + in the bottom bar: in the app it writes a real file into the workspace. Here it only says what it would write. The parts a browser cannot show are the Taptic Engine, sheets springing from the bottom edge, and pinch-to-zoom.
